## 🎙️ 开源项目：whisperMe 语音听写

### 一个基于 ASR-LLM 的播客后期提效工具

* **核心痛点**：一小时播客音频，人工转写+校对需要 **3小时以上**，效率低、成本高。
* **架构设计**：
  ```
  播客音频 ──> OpenAI Whisper ──> 标点与段落智能修复 (LLM) ──> 语气词/口水话过滤 (LLM) ──> 自动 ShowNotes / 时间戳
  ```
* **取得成效**：
  * 语音转写与整理效率提升 **90% 以上**。
  * 跑通了 **音频 ──> 大模型 ──> 结构化数据** 管道的闭环。

## 💔 宠物上门喂养的三大“硬伤”

* **猫咪寄养应激**
  * 猫是高度敏感的领地动物，寄养极易应激生病，“上门喂养”是刚需。
* **信任黑箱**
  * 宠物主把钥匙交出去后的巨大焦虑：换水了吗？加粮了吗？猫砂铲了吗？
* **服务汇报效率瓶颈**
  * 伴宠师双手要洗碗、倒罐头、铲屎，根本腾不出手打字向宠物主汇报，报告编写成本高，单人日接单量受限。

## 🎤 伴宠师“免手写”语音报告

### whisperMe 核心能力的延伸

* **服务场景**：伴宠师一边洗碗/铲屎，一边开启录音随口记录喂养动态。
  > *“大福今天精神挺好，吃了一大半罐头，猫砂盆里拉粑粑正常，稍微有点软便……”*
* **AI 自动化处理 pipeline**：
  ```
  口语碎碎念音频 ──> whisperMe ASR ──> LLM 情感润色与结构化过滤 ──> 生成精美卡片式《喂养日报》 ──> 微信推送
  ```
* **效果**：伴宠师只需开口说话，3秒内生成专业温馨的文字日报，省去打字成本。

## 🔍 AI Vision 智能对比核验

### 用客观技术数据，打破信任黑箱

* **打卡核验机制**：伴宠师上门时需拍摄清理/倒粮前后的食盆和猫砂盆照片。
* **AI 视觉比对**：
  * **食碗比对**：AI 自动比对加粮前后的分量与分布变化，核准倒粮分量。
  * **水碗比对**：AI 自动核算水位高度差，客观证实已换新水。
  * **猫砂盆比对**：比对清理前后状态，核验铲除动作。
* **效果**：将只能靠自觉的服务过程，转化为可被技术客观核验的透明数据。
