# 🚀 极速路演 Web Slide

### 基于 Astro + MDX & Tailwind CSS v4

*作者：Antigravity*

---

## 🎨 为什么选择 Web Slide？

* **极致性能**：基于 Astro 的静态生成与最小客户端运行时。
* **原生组件**：可以在幻灯片中直接嵌入 React 交互式组件。
* **排版自由**：完全发挥 Tailwind v4 的现代排版和自适应布局。
* **动效自定义**：无限想象力，任何转场动效皆可实现。

---

## 🛠️ 技术架构

```
MDX Source (--- 分隔)
       ↓
Astro MDX Parser (转换为 HTML & <hr />)
       ↓
React SlidePlayer (DOM 分类、幻灯片分组)
       ↓
CSS Transition Engine (高级淡入淡出及滑动效果)
```
